# 콘텐츠 운영

## 시작과 홈 게시

`/admin`에서 등록된 GitHub 계정으로 로그인합니다. 홈 편집에서 이름·직무·소개·사진·이메일·링크·이력서, About me, Education, Stack, Experience를 입력합니다. 항목의 위/아래 버튼으로 순서를 바꿀 수 있습니다. 같은 그룹명을 가진 Stack 기술은 함께 표시됩니다.

대표 프로젝트를 선택해 순서를 정하고 홈의 프로젝트·블로그 노출 수를 설정합니다. 기본값은 3개씩이며 실제 공개 콘텐츠 수만 표시합니다. **저장과 홈 변경사항 게시는 별개입니다.** 자동저장·파일 업로드·미리보기만으로 공개 화면이 바뀌지 않습니다. 홈 게시 시 관련 정보 전체를 한 번에 교체합니다. 비어 있는 섹션과 메뉴는 함께 숨겨집니다.

## 프로젝트·블로그

콘텐츠 화면에서 새 글을 만듭니다. 제목·slug·요약·대표 이미지·대체 텍스트·카테고리·태그를 지정합니다. 게시하려면 제목·slug·카테고리가 필요합니다. 대표 이미지가 없으면 제목 중심 카드가 됩니다. 공유 이미지는 별도 공유 이미지 → 대표 이미지 → 제목 기반 생성 순서입니다.

프로젝트는 기본 본문 템플릿과 기간·진행 상태·역할·팀 규모·기술·외부 링크를 제공합니다. 기술은 먼저 홈 Stack에서 게시해야 선택할 수 있습니다. 프로젝트의 진행 상태와 게시물 공개 상태는 서로 독립적입니다.

입력 중단 1초 후 초안만 저장합니다. 한국어 입력 조합 중에는 저장을 미룹니다. PC는 입력·미리보기 분할, 모바일은 탭 전환을 사용합니다. 미리보기와 공개 본문은 같은 GFM 렌더러를 사용합니다. 원시 HTML·MDX·영상·수식·다이어그램 실행은 지원하지 않습니다.

**수정사항 게시**를 누르면 본문과 메타데이터가 함께 반영됩니다. 기존 공개본은 그때까지 유지됩니다. 수정사항 폐기는 초안을 현재 공개본으로 되돌립니다. 처음 게시한 날짜는 비공개·휴지통·복원·재게시로 바뀌지 않습니다. 표시 시각은 한국 시간입니다.

slug는 제목 수정으로 자동 변경하지 않습니다. 직접 변경해 게시하면 기존에 게시된 주소는 새 주소로 연결됩니다. 다른 글의 현재/과거 주소를 재사용할 수 없습니다. 미게시 초안의 slug 예약은 공개 주소로 연결되지 않습니다.

## 실패와 복구

저장 중/완료/실패, 마지막 저장 시각과 서버 버전을 확인합니다. 실패를 성공으로 표시하지 않습니다. 세션 만료 시 편집 창을 유지하고 안내 링크로 새 창에서 `/admin`에 다시 로그인한 후 저장을 재시도하세요.

기기 임시복구는 IndexedDB에 계정·콘텐츠·탭별로 보관합니다. 한 탭의 저장 성공으로 다른 탭의 미저장 복구본을 지우지 않습니다. 새로 열 때 서버 초안과 다르면 복구 안내가 나타납니다. 서버 버전과 복구본 기반 버전을 비교하고 복구, 서버 유지 또는 복구본 다운로드를 선택합니다. 오래된 복구본을 자동으로 서버에 덮어쓰지 않습니다. 공유 기기에서는 명시적으로 로그아웃하여 복구 데이터를 지웁니다. 서버 저장이 완료된 동일 내용의 복구본은 정리됩니다.

여러 탭이 동시에 편집하면 오래된 버전의 저장은 409 충돌로 거절됩니다. 서버 초안을 다시 조회하면 복구본을 보존한 상태로 비교할 수 있습니다. **게시 후 캐시 갱신 실패**는 별도로 안내하며 캐시 갱신 재시도 버튼을 사용합니다. 데이터를 다시 게시할 필요가 없습니다.

## 비공개·휴지통·삭제

비공개로 전환하면 홈·목록·상세·관련 글·사이트맵·공유 이미지에서 제외됩니다. 휴지통도 공개되지 않으며 자동 삭제하지 않습니다. 복원은 과거 공개본이 있으면 비공개, 없으면 초안으로 돌아갑니다. 영구 삭제는 휴지통에서 확인 후 수행합니다. 연결된 파일은 자동 삭제하지 않습니다.

이미지는 확장자와 실제 유형을 함께 검사하며 최대 4.5MB입니다. 외부 이미지 주소는 가져오기를 거쳐 저장소 파일로 삽입합니다. 본문에는 `/media/<id>` 형식의 저장 파일을 사용합니다. 가져오기에 실패하면 직접 업로드하세요. 미게시 이미지에는 관리자만 접근할 수 있습니다. 다른 공개 콘텐츠에서 이미 쓰는 이미지는 초안에서 재사용해도 계속 공개됩니다.

이력서 교체도 업로드 → 홈 초안 선택 → 홈 게시 순서입니다. 방문자 주소 `/resume`과 `/resume?download`는 유지됩니다. 사용처에 공개본·초안이 하나라도 남은 파일은 삭제되지 않습니다. 모든 참조를 제거하고 필요한 게시 작업을 완료한 후 미디어에서 삭제하세요. 이미 방문자가 다운로드한 파일까지 회수할 수는 없습니다.

## 분류와 내보내기

분류 이름 변경·병합·삭제는 초안 자동저장과 다른 전역 관리 작업입니다. 사용 중인 카테고리는 다른 카테고리로 재배정하고, 태그 삭제 시 영향받는 콘텐츠 수를 확인한 뒤 연결을 해제합니다. 변경된 분류를 편집하던 다른 탭은 충돌을 안내합니다.

전체 내보내기는 관리자 메뉴에서 ZIP을 다운로드합니다. `manifest.json`에 메타데이터·분류·버전별 파일 연결·홈 설정을, 콘텐츠별 폴더에 공개본/초안 Markdown을, `files/<미디어ID>/`에 직접 저장한 파일을 담습니다. 관리자 인증 상태에서만 스트리밍하며 공개 다운로드 URL을 만들지 않습니다. 실패한 ZIP은 폐기하고 다시 다운로드하세요. 자동 백업과 가져오기 UI는 제공하지 않습니다. 영구 삭제나 대규모 수정 전 수동 내보내기를 권장합니다.
