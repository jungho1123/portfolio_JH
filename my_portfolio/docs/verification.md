# 검증 결과

검증일: 2026-11-07. Node.js 26.13.0, pnpm 12.16.1에서 실행했습니다. 이 문서의 통과는 명시한 테스트 환경에 한정되며, 실제 Vercel 운영 배포 완료를 의미하지 않습니다.

## 실행 결과

| 검사                    | 결과                                                                                                                                                    |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm lint`             | 오류·경고 없이 통과                                                                                                                                     |
| `pnpm build`            | 프로덕션 빌드·TypeScript·정적 셸 생성 통과                                                                                                              |
| `pnpm test`             | 단위·실제 PostgreSQL 통합 테스트 12개 통과                                                                                                              |
| `pnpm test:e2e`         | Chromium E2E 13개 시나리오 통과. 전체 12개 실행 후 변경 영역 2개와 신규 Stack 제거 시나리오 1개를 선별 검증                                             |
| `git diff --check`      | 통과                                                                                                                                                    |
| Neon 연결·마이그레이션  | 연결 성공, 기존 2개와 신규 2개 마이그레이션 적용 확인                                                                                                   |
| 실제 비공개 Vercel Blob | 제한된 클라이언트 토큰으로 4,500,000바이트 직접 업로드·인증 조회·익명 차단 통과. 점검 객체 삭제 완료                                                    |
| 프로덕션 실행 점검      | 연결된 Neon을 사용하는 `next start`에서 홈·두 목록·관리자·사이트맵·한국어 자동 공유 이미지 200, 비로그인 관리 API 401, 없는 상세·미등록 이력서 404 확인 |

E2E는 Docker의 임시 PostgreSQL과 별도 포트의 Next.js 서버를 사용했습니다. 테스트용 프로필·글·계정·세션은 임시 DB에만 생성했으며 실제 Neon 공개 콘텐츠로 게시하지 않았습니다. 허용/미허용 OAuth 콜백은 GitHub 응답을 모의하고, 메모리 어댑터 및 실제 Prisma/PostgreSQL 어댑터에서 각각 계정·세션 생성 여부를 확인했습니다.

브라우저 테스트는 Linux 브라우저 공유 라이브러리를 사용자 캐시에 설치하고 `LD_LIBRARY_PATH`로 제공한 환경에서 실행했습니다. 일반 Linux 환경은 `pnpm exec playwright install-deps chromium` 또는 관리자가 제공한 동일 라이브러리가 필요합니다. 스크린샷은 무시된 `test-results/`에 저장됩니다.

## 운영 전 남은 작업

- 실제 이름·직무·소개·학력·경력·프로젝트·사진·공개용 PDF 입력 및 게시. 임의 경력이나 성과는 넣지 않았습니다.
- Vercel 프로젝트·운영/Preview 자원 분리·대표 도메인 연결·실제 GitHub OAuth 콜백 왕복 확인.
- `SITE_URL`, `CRON_SECRET` 등 운영 환경별 값을 설정하고 GitHub 공개 활동 토큰의 권한을 확인.
- 운영 환경에서 관리자 직접 업로드, PDF 교체, 파일 포함 ZIP, 캐시 접근 회수, 재배포 후 영속성 검증.
- 사용할 플랜과 월 지출 한도 결정. 무료 운영을 보장하지 않으며 비용 항목은 배포 문서에 정리했습니다.

실행하지 않은 항목은 통과로 처리하지 않았습니다. 애플리케이션에 테스트용 인증 우회나 임시 영속 저장 대체 경로는 없습니다.
