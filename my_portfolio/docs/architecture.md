# 설계 선택

- 기존 App Router·Prisma·Better Auth를 유지해 프레임워크 교체 범위를 줄였습니다. 누락된 인증 구현과 Prisma 모델을 복원하고 기존 인증 마이그레이션을 보존했습니다.
- Neon은 기존 PostgreSQL 어댑터와 호환되며 Vercel Marketplace에서 연결·결제를 관리할 수 있습니다. 파일은 비공개 Blob 하나에 보관하여 초안 파일 복사나 공개 URL 회수 문제를 줄입니다.
- 파일 경로를 사이트에서 중계하고 매 요청의 현재 공개 참조/관리자 세션을 검증합니다. Next Image의 공개 최적화 캐시는 사용하지 않고 인증 후 Sharp로 축소합니다. 브라우저·공유 CDN 캐시에 민감한 파일 응답을 남기지 않습니다. 이 선택에는 Function 및 전송량 비용이 있습니다.
- 콘텐츠는 공통 Content와 두 개의 현재 Revision을 사용합니다. JSONB는 홈의 구조화된 편집과 공통 Markdown 메타데이터를 함께 다루고, 분류·미디어 참조는 관계 테이블로 유지하여 DB의 참조 제약을 활용합니다. 상세 버전 이력 UI는 만들지 않습니다.
- 상세 주소의 단일 DB 조회를 수행하는 Proxy가 스트리밍 시작 전에 404/308 상태를 결정합니다. 실제 본문과 파일의 접근 검증은 각 서버 조회에서도 수행합니다.
- 현재 공개 포인터와 상태는 요청마다 DB에서 확인합니다. 홈의 불변 공개 스냅샷만 Next 캐시에 보관하며 목록·상세·파일·공유 이미지는 최신 공개 상태를 조회합니다. 게시 후 CacheJob으로 무효화 실패를 추적합니다.
- CodeMirror는 일반 Markdown 입력과 한국어 조합을 지원합니다. react-markdown/GFM 렌더러를 편집 미리보기와 공개 페이지가 공유하고 HTML을 실행하지 않습니다. 이미지 URL은 관리하는 미디어 경로만 렌더링합니다.
- SSR 목록과 페이지별 탐색 링크로 크롤러가 후속 콘텐츠를 찾을 수 있습니다. 방문자용 추가 로딩은 DB에서 날짜+ID 커서로 12개씩 처리하며 전체 본문을 브라우저에 미리 내려보내지 않습니다.
- 기준 디자인의 좁은 콘텐츠 폭·분할선·여백·프로필 배치에서 출발하고, 실제 개인 정보가 없는 최초 화면에는 가상의 경력이나 프로젝트를 작성하지 않습니다.
